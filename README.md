# claude

Projects built with Claude. Each folder is self-contained and has its own README.

| Project | What it is | Open |
|---|---|---|
| [`study-site/`](study-site/) | Single-page study site for IB and diploma subjects: lessons, quizzes, spaced repetition, achievements, optional Google sign-in sync. | `study-site/index.html` |
| [`habit-tracker/`](habit-tracker/) | Monthly habit tracker as a phone app, a desktop web app and a spreadsheet, with streaks, year heat map, journal flashcards and backups. | `habit-tracker/index.html` (phone), `habit-tracker/web/index.html` (desktop) |
| [`wavelength/`](wavelength/) | A music player modelled on Spotify, styled as a monochrome terminal full of flowers. Plain HTML, CSS and JavaScript. | `wavelength/index.html` |

All three run from a single HTML file with no build step, and keep their data in the browser unless the project's README says otherwise.
